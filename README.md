
Proyecto CAPAZ
Este repositorio contiene el código fuente de un sitio web de e-commerce estático para la marca de moda sostenible CAPAZ. El sitio está diseñado para ser una vitrina de productos, gestionando un carrito de compras local y dirigiendo todas las interacciones de compra y contacto a través de WhatsApp.

Basado en la filosofía descrita en nosotros.html, el pilar de la marca es el upcycling: rescatar y revalorizar residuos textiles y ropa de segunda mano para transformarlos en prendas únicas, modernas y sostenibles con un enfoque en la cultura colombiana.
